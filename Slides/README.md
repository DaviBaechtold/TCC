Slides para a apresentação do TCC (Lifting 2D->3D).

Como compilar:

1. Usando pdflatex:
```bash
pdflatex -output-directory Slides Slides/Lifting_Presentation.tex
```

2. Recomendo usar latexmk:
```bash
latexmk -pdf -output-directory Slides Slides/Lifting_Presentation.tex
```

Se faltar pacotes LaTeX, instale uma distribuição completa (TeX Live) ou os pacotes específicos.
